# 企业裁员监测与员工权益保护

基于 X 热搜话题 "腾讯 28 周年会议，马化腾讲话，组织变革，人员调整，可能整体裁员 15% 以上"（955K 曝光）开发的裁员监测 MVP。

## 功能

- **裁员信息监测**：追踪主要企业裁员动态（规模、部门、原因、状态）
- **经济补偿计算器**：N+1 补偿金计算，支持法定上限
- **员工权益知识库**：8 篇权益文章（补偿计算、通知程序、优先留用、禁止裁员等）
- **求职市场**：职位 listings 与技能匹配
- **记录管理**：个人裁员观察记录

## 技术栈

Node.js + Express + 纯 HTML/CSS/JS

## 运行

```bash
npm install
npm start
```

访问 http://localhost:3000
